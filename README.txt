ЦКС — Робочий офіс

Файли (тримайте разом в одній папці):
index.html  — каркас сторінки
style.css   — кольори, шрифти, розміри
app.js      — уся логіка програми
config.js   — налаштування бази даних (адреса та ключ Supabase)
schema.sql  — схема бази даних (виконати один раз у Supabase)
Img/        — ваші іконки та логотип

Режими роботи
1) config.js порожній — дані зберігаються тільки в браузері (для перегляду дизайну).
2) config.js заповнено — акаунти, відділи, задачі й файли зберігаються в базі,
   усі користувачі бачать одні й ті самі дані в реальному часі.

Увімкнення бази (Supabase, безкоштовний тариф підходить для старту)
1. supabase.com → New project. Дочекайтесь створення.
2. SQL Editor → New query → вставте вміст schema.sql → Run.
3. Project Settings → API: скопіюйте Project URL та anon public key у config.js.
4. Authentication → URL Configuration: у Site URL вставте адресу вашого сайту
   (для листів підтвердження та відновлення пароля).
5. Authentication → Providers → Email: за бажанням увімкніть/вимкніть
   «Confirm email» (підтвердження пошти).
6. Завантажте всі файли на хостинг (GitHub Pages / Netlify) і зареєструйтесь.
   Перший зареєстрований користувач отримує повний доступ.
